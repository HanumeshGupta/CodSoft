## 🐍 Python Projects

### ✅ To-Do List
A simple **task management system** built with Python. Users can add, delete, and mark tasks as complete.

- **Features:**
  - Add new tasks
  - Mark tasks as completed
  - Delete tasks
  - Save and load tasks

### 🖩 Calculator
A **basic calculator** that supports arithmetic operations like addition, subtraction, multiplication, and division.

- **Features:**
  - Supports multiple operations
  - User-friendly CLI interface
  - Error handling for invalid inputs

### ✊ Rock-Paper-Scissors
A **Python-based game** where users can play against the computer.

- **Features:**
  - Randomized AI opponent
  - Simple CLI-based interface
  - Win/loss tracking

## 🤖 Machine Learning Projects

### 🛡️ Credit Card Fraud Detection
A **machine learning model** that detects fraudulent transactions using **classification algorithms**.

- **Tech Stack:** Python, Pandas, Scikit-Learn
- **Dataset:** Credit card transactions
- **Model Used:** Logistic Regression, Random Forest

### 📉 Customer Churn Prediction
A predictive model that determines whether customers are likely to leave a company based on their **usage behavior**.

- **Tech Stack:** Python, TensorFlow, Pandas
- **Dataset:** Customer subscription data
- **Model Used:** Decision Trees, Neural Networks

### 📩 SMS Spam Detection
A **Natural Language Processing (NLP) project** that classifies SMS messages as spam or ham (non-spam).

- **Tech Stack:** Python, NLTK, Scikit-Learn
- **Dataset:** SMS messages dataset
- **Model Used:** Naïve Bayes, Support Vector Machines

- **Model Used:** Logistic Regression, Decision Trees

## 🚀 Getting Started

### 🛠️ Prerequisites

- **Python 3.8+** 🐍
- **Required Libraries:** NumPy, Pandas, OpenCV, TensorFlow, Scikit-Learn
- **Jupyter Notebook** (optional for ML projects)

### 📥 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/HanumeshGupta/CodSoft.git
   cd CodSoft_Projects
   ```
2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 🎯 Usage

Run specific projects using Python:

```bash
python To-Do_List.py   # Run the To-Do List project
python calculator.py    # Run the Calculator
python rock_paper_scissors.py  # Play the Rock-Paper-Scissors game
```

For **Machine Learning & Data Science projects**, open the corresponding Jupyter Notebook:

```bash
jupyter notebook Credit_Card_Fraud.ipynb
jupyter notebook Customer_Churn_Prediction.ipynb
jupyter notebook sms_spam_detection.ipynb
jupyter notebook IMDB_movie_rating.ipynb
jupyter notebook Titanic_model.ipynb
```
